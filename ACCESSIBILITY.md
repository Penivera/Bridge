# Accessibility Guidelines

Bridge welcomes contributions that improve accessibility across documentation, website content, and tooling interfaces.

## Documentation Accessibility

- Use clear, direct language.
- Structure content with logical heading levels.
- Include descriptive link text.
- Provide alt text for meaningful images and diagrams.
- Avoid relying only on color to convey meaning.

## Website and UI Contributions

When contributing to web-facing content, aim to:

- Keep sufficient text/background contrast.
- Ensure keyboard-accessible navigation and controls.
- Associate labels with interactive elements.
- Preserve visible focus indicators.
- Validate semantic HTML structure.

## Reporting Accessibility Issues

If you find an accessibility issue, open an issue using the repository templates and include:

- Where the issue appears
- Steps to reproduce
- Expected accessible behavior
- Suggested improvement (if known)
